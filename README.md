# 오늘의 한마디 — Daily Micro-Cheer
Apps in Toss용 초경량 비게임 미니앱 MVP.

## Local
npm install
npm run dev

## Web build
npm run build:web

## AIT build
앱인토스 콘솔 appName과 설정을 맞춘 뒤 최신 공식 SDK/CLI 기준으로 `npm run build`.

## Important
현재 공식 문서(2026-09-17 확인)에는 Web Framework 3.x 및 `apps-in-toss.config.ts` 마이그레이션 안내가 존재한다. 실제 출시 시점의 공식 문서로 버전/명령을 다시 확인한다.
